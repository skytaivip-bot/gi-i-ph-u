# Đăng Giải Phẫu Lab miễn phí

1. Tạo một kho mới trên GitHub, chọn **Public**.
2. Tải **toàn bộ nội dung trong thư mục này** lên cấp gốc của kho. Tệp `index.html` phải nằm ở cấp gốc.
3. Mở **Settings → Pages**. Chọn **Deploy from a branch**, nhánh `main`, thư mục `/(root)`, rồi bấm **Save**.
4. Chờ GitHub hiển thị đường dẫn web. Mở đường dẫn đó trên điện thoại hoặc máy tính.

Trang chỉ là HTML/CSS/JavaScript tĩnh. Không có máy chủ riêng, không gửi câu trả lời đi đâu và không dùng localStorage/cookie; điểm số và danh sách câu cần ôn sẽ mất khi tải lại trang.
